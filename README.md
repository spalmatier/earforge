# EarForge (Interval Trainer)

An interactive music theory and ear-training app built with React, Vite, and VexFlow.

## 🎵 Features

- Melodic and harmonic interval training
- Treble and bass clef support
- Key signatures (sharps & flats)
- Interactive interval builder mode
- Audio playback using Web Audio API
- Staff notation rendering with VexFlow

## 🎼 Tech Stack

- React
- Vite
- VexFlow
- Web Audio API

npm install
